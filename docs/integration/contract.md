# Draft fusion input contract (v1)
Each module will eventually output: schema_version, sample_id, module, timestamp,
attack_probability, predicted_label, model_version.
Positive class and probability calibration need an agreed definition.
Datasets collected independently must not be treated as synchronized multi-signal events.
Missing modalities and sensor clocks must be handled explicitly.
This is an initial software contract, not evidence that fusion is scientifically validated.
